# Video Downloader

A simple video downloading tool with user accounts and subscriptions.

## Tech Stack

- Backend: Rust (Axum)
- Frontend: React + Vite
- Database: SQLite
- Payments: Stripe

## Development

```bash
# Backend
cd backend
cargo run

# Frontend
npm install
npm run dev
```

## Deployment

```bash
docker-compose up -d
```

## Environment Variables

See `.env.example` for required variables.
